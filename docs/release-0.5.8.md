# 0.5.8 —— mac 面板也长成四个页签了

> 这份是发 GitHub Release 用的正文草稿（中文），复制粘贴即可。英文见 [release-0.5.8.en.md](release-0.5.8.en.md)。

一句话：**macOS 的面板从「一页纵向」改成四个页签（读数 / 控制 / 模式 / 曲线）**，跟 Windows 版长得一样，
曲线页也补上了「哪一路在输出一眼就看出来」。Windows 这边只是跟着编号，代码与 0.5.7 相同。

## 这次改了什么

### macOS 0.1.9：四个页签 + 曲线页

以前 mac 的面板是一页塞到底：四路读数、每路开关、四种充电模式全挤在 340×424 里，没有走势图。
现在跟 Windows 一样分页：

* **读数**：四路各多少伏 / 多少安 / 多少瓦，右边是那一口的**单口采集**按钮
* **控制**：每路一个开关，一行一个（原来跟读数挤在一起，容易点错行）
* **模式**：AI / 数码生态 / 单口 / 均衡，当前档打勾 + 绿边
* **曲线**：新增 —— 四路各一条线（C1 蓝 / C2 绿 / C3 橙 / A 紫；C3 与 A 合并时报合并值的那一路写 **C3+A**）

曲线页回答的是和 Windows 0.5.7 同一个问题：**单口输出时怎么认出那条线**。

* **副标题直接点名**：「在输出：C3」「在输出：C1、C3」；一路都没有时才回到「每路一条线，点右边换时长」
* **线末端写口名**：每条线最后一个有效点旁边同色标出 C1 / C2 / C3（或 C3+A）/ A，
  标签按纵向错开、靠右时改写到点的左侧，底下垫一层半透明块
* 没出过力的那几路只把图例压暗、不画线
* 时长四档：点右上角胶囊在 **1 / 5 / 15 / 30 分钟**之间循环，写进 `config.json` 的 `chartSeconds`
* 历史**只活在内存里**（1 Hz × 30 分钟 = 1800 点封顶，约 72 KB），程序退出就没了。要留数据请用单口采集导出 CSV
* 拔线、没读数、合并时被并进去的那一路记 -1，曲线在那儿**断开**，不会画成「平滑下降」

顺带修了一个自己写出来的小 bug：时钟回退（系统休眠 / 校时）时，新的一拍会被当成「来得太快」丢掉，
曲线就停在旧数据上不动了 —— 现在先清空重来，再判断节流。

### Windows：只是跟着编号

* 0.5.7 → **0.5.8**，代码没有改动（这次同一版里只有 mac 的活）
* 已经装了 0.5.7 的可以不动；要跟上「检查更新」的版本号，覆盖一次也行

## 怎么升级

* **macOS**：下载 `CuktechTray-0.1.9-mac.zip`，解压把 `CuktechTray.app` 拖进「应用程序」覆盖旧的；
  第一次打开要右键 → 打开（ad-hoc 签名，没有 Apple 开发者账号）
* **Windows 绿色版**：把新的 `CuktechTray.exe` 覆盖旧的，`settings.json` 原样接着用
* **Windows 装过本机的**：托盘右键 →「检查更新」，它自己下载、校验 SHA256、重启换掉自己

## 系统要求

* Windows 10 2004（内部版本 19041）及以上，x64；不需要装运行时（NativeAOT 单文件）
* macOS 13 或更新，Apple Silicon 与 Intel 都行（universal）
* 硬件还是「酷态科 10 号 Ultra」充电器 + 蓝牙（BLE）

## 已知

* Windows 的 exe **没有代码签名**，首次运行会弹蓝色的「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可
* macOS 的 .app 是 ad-hoc 签名，第一次打开要在「隐私与安全性」里点「仍要打开」
* mac 面板的曲线历史只在内存里，关掉 App 就清零（这一点和 Windows 一样）
