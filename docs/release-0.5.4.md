# 0.5.4 —— 曲线页、导出 CSV、自己在后台查更新

> 这份是发 GitHub Release 用的正文草稿（中文），复制粘贴即可。英文见 [release-0.5.4.en.md](release-0.5.4.en.md)。

一句话：面板多了**第四个页签「曲线」**，单口采集能**导出 CSV**，更新检查会**自己启动时查一遍**并在托盘图标上点红点；
[issue #7](https://github.com/Blank2007/cuktech-ultra-tray/issues/7) 说的「任务栏数字挪不到右边」也修了——现在位置和大小都能在菜单里直接选。

## 这次改了什么

### 曲线页（面板第四个页签）

* 四路各一条线：**C1 蓝 / C2 绿 / C3+A 橙 / A 紫**，颜色跟读数页左边的色条是同一套
* 横轴时长四档，点右上角胶囊循环 `1 → 5 → 15 → 30` 分钟；右键菜单「功率曲线时长」里也能选，写进 `settings.json` 的 `ChartSeconds`
* 纵轴按 20 W 一档自动取顶，插 65 W 笔记本也不会把手机的线压成贴底的一条；底部给这一窗的峰值与平均
* **只活在内存里**：每秒一点、30 分钟 1800 点封顶（约 72 KB），关掉程序就没了，不写任何文件
* 拔线 / 空载 / C3+A 合并时被并进去的那一路记成「没有数」，曲线在那儿**断开**；整段都没有输出的口干脆不画，
  图例压暗——否则全 0 的那一路会在 0 轴上多出一条看着像坐标轴的横线
* 两次采样间隔小于 0.4 秒不记：设备偶尔连着推两帧，记下来只是让曲线多几个重复点

### 单口采集导出 CSV

* 采集时顺带把每一秒的电压 / 电流 / 功率 / 是否带载存进内存（上限 7200 条 ≈ 2 小时）
* 窗口按钮改成两排：上排「开始采集 / 停止」+「关闭」，下排「复制摘要」+「**导出 CSV**」（窗口高度 482 → 534）
* 落到 `文档\CuktechTray\cuktech-capture-<口名>-<yyyyMMdd-HHmmss>.csv`，**UTF-8 带 BOM**（不带的话 Excel 打开中文表头是乱码），
  数字一律按不变区域写（否则有的系统小数点是逗号，整张表会错列）
* 采集过程本身仍然不落盘，写文件只发生在你按「导出 CSV」的时候

### 启动时自己查一遍更新

* 默认每次启动 **8 秒后**查一次（先让蓝牙连上，不跟握手抢网络和 CPU）；设置文件里 `CheckUpdatesOnStart`，菜单里也能关
* 查到新版：托盘图标右上角点一颗**红角标**，菜单里那一项变成「检查更新…（有 0.5.5）」并带一个**小红点**，再冒一个气泡
* 自动查**不拿弹框拦人**：只有你自己点「检查更新…」才会弹「已经是最新版」或问要不要现在替换；已经最新就把红点悄悄收掉

### 任务栏数字挪不到右边（issue #7）

* 位置改成直接选：**自动**（开始按钮左边）/ **居中** / **靠右**（托盘左边）/ **自定义左边距**
* 大小四档：小 / 中 / 大 / 自定义宽度（56~160），**字号跟着宽度走**（11 × 宽 / 84），拉宽不会把字切掉
* 真正的根因：挂上任务栏之后**再没动过 z 序**，一拖到托盘区就被托盘窗口整块盖住，看着就是「挪不过去」。
  现在每次重排都把它提到兄弟窗口最前；拖动中捕获被抢走也会正常收尾，不再卡在「正在拖动」

### 其他

* **没配对就不起蓝牙循环**：Mac 还空着的时候，以前每轮都抛 `MAC 格式应为 AA:BB:CC:DD:EE:FF` 刷一屏日志、还白占着适配器
* `tools/check-ui.ps1` 基线重录（多了曲线页两张图，采集窗口因按钮改两排变成 360×534）
* 版本号 0.5.3 → **0.5.4**

## 怎么升级

* **绿色版**：把新的 `CuktechTray.exe` 覆盖旧的，`settings.json` 原样接着用
* **装过本机的**：托盘右键 →「检查更新」，它自己下载、校验 SHA256、重启换掉自己
* 从这版起，什么都不做也会在启动 8 秒后告诉你有没有新版（红角标 + 菜单里那句「有 x.y.z」）

## 系统要求

* Windows 10 2004（内部版本 19041）及以上，x64
* 不需要装运行时：NativeAOT 单文件
* 硬件还是「酷态科 10 号 Ultra」充电器 + 蓝牙（BLE）

## 已知

* exe **没有代码签名**，首次运行会弹蓝色的「Windows 已保护你的电脑」，点「更多信息 → 仍要运行」即可
* macOS 版这次没有跟着动（还是 0.1.7），曲线页和任务栏那块是 Windows 专有；CSV 导出会同步到 mac 的下一个版本
* 「任务栏数字」的位置和大小在菜单里选完就立刻生效，不需要重启
