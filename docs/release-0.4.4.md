# 0.4.4 —— 顶栏那个「已连接」不再铺一层绿底，面板长高 8 px

> 这份是发 GitHub Release 用的正文草稿（中文），复制粘贴即可。英文见 [release-0.4.4.en.md](release-0.4.4.en.md)。

一句话：顶栏的「已连接」胶囊去掉半透明绿底、只留圆点和文字，顺手把标题行与页签行拉开 8 px，
面板设计尺寸 320×396 → **320×404**。

## 这次改了什么

### 0.4.4（本版）

* **「已连接」去掉底色**：原来是一层 30% 透明的绿底 + 状态色圆点 + 「已连接」三个字；现在不铺底、不描边 ——
  一个直径 8 px 的圆点 + 原来的 11.5f 状态文字，右对齐位置不变（要的就是去掉底色，字是要留着的）
* **顶栏留白**：状态离右边那枚图钉从 6 px 拉到 10 px
* **面板长高 8 px**：标题行与页签行原来只差 4 px，看着像粘在一起；页签行下移 8 px（38 → 46），
  大数字、分隔线、表头、四行读数、页脚整体跟着下移 8，面板 320×396 → **320×404**
* 版本号 0.4.3 → 0.4.4；三张面板截图按新顶栏重出（`docs/shot-panel.png`、`docs/shot-control.png`、`docs/shot-mode.png`）

### 0.4.2

* **四角黑块修掉**：圆角以前只是「拿圆角路径画了一块背景」，窗口本身还是矩形，双缓冲是屏幕兼容 DDB（没有 alpha
  通道），没被画到的四角就剩底色。现在跟菜单、向导一样用 `SetWindowRgn` + `CreateRoundRectRgn` 把窗口本身裁成圆角
  （半径取同一个整数值，抗锯齿边缘不会漏半像素）；`--render` 导出的图也把四角抠成透明
* **排版松一档**：面板 320x360 → 320x396，四行读数行距 42 → 48，页脚跟着下沉 36；模式页卡片 44 → 50 高、
  间距 52 → 58；控制页/模式页顶部说明文字下移 8 像素，与放高的表头重新对齐；隔行底纹 32 → 36 高

### 0.4.1

* **扫码向导回到原生外壳**：新增 `src/CuktechTrayAot/WizardWindow.cs`（欢迎 / 扫码 / 选设备三页，425 行，
  460x520 设计尺寸自绘）。二维码从米家服务器现取现画，选完设备直接把 MAC + token 写进 `settings.json` 并重连，
  不用重启；`settings.json` 里没有凭据时启动 0.8 秒后自动弹，托盘菜单「重新配置设备…」走同一套
* **界面再对齐 0.3.3**：模式页、控制页顶部那行说明文字各修正 4 个逻辑像素的基线，三页 12 行文字的纵向行段与 0.3.3 完全重合
* 新增开发用参数：`--render-wizard`（没有真屏也能把向导三页渲成 575x650 的 PNG）；修掉渲染输出路径里反斜杠被转义吃掉的 bug

## 怎么升级

* **绿色版**：把新的 `CuktechTray.exe` 覆盖旧的就行，`settings.json` 原样接着用，配置不会重置
* **装过本机的**：托盘右键 →「检查更新」，它自己下载、校验 SHA256、重启换掉自己；也可以直接替换
  `%LOCALAPPDATA%\Programs\CuktechTray\CuktechTray.exe`
* **命令行等价物**：`--install [--dir=<路径>] [--autostart] [--desktop] [--silent]` 装到本机，
  `--uninstall [--silent]` 从头拆干净（快捷方式、HKCU 卸载项、目录），全程不弹 UAC
* **要重新配对设备**：`--setup` 直接叫出扫码向导（和托盘菜单「重新配置设备…」是同一条路径）

## 已知

* 这个 exe **没有代码签名**，首次运行会弹蓝色的「Windows 已保护你的电脑」，
  点「更多信息 → 仍要运行」即可；之后不会再问
* 自动更新只认名字形如 `CuktechTray-<版本>.exe` 的发布资产（含 `Setup` 的会被跳过），
  所以 `dist\CuktechTray-0.4.4.exe` 是照这个名字另存的一份，传 Release 资产请用它，别传 `CuktechTray.exe`
* `--render` / `--font-probe` / `--alpha-probe` / `--update-selftest` 这些是开发自查用的开关，
  正常使用不用管；`--apply-update` 别手敲（它会把指到的 exe 换成载荷）
